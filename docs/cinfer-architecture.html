c-infer · Systems Architecture Specification

Zero-Allocation Neural Inference Runtime

Offline model topology serialization in Python paired with a deterministic, allocation-free execution engine in pure C11.

Guarantees

Zero Heap at Runtime

Memory required for activations, layers, and tensor ping-ponging is computed once during initialization. Hot forward passes perform 0 allocations.

Portability

No Heavy Dependencies

Runs on microcontrollers, RTOS, or POSIX systems with standard C11. Avoids massive BLAS or matrix libraries by implementing vector operations natively.

Rigor

Strict Parity Testing

Every single layer (Linear, Conv2D, MaxPool, activations) is verified against reference PyTorch tensors within 1e-5 floating point deviation.
