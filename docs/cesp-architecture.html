c-esp v1.1.0 · Architecture Specification

Zero-Allocation Sans-IO IPsec ESP Data-Plane Engine

In-place RFC 4303 packet framing with dual constant-time AEAD backends (RFC 7634 ChaCha20-Poly1305 at 6.81 cpb & table-free RFC 4106 AES-256-GCM), RFC 4301 5-tuple Security Policy Database (SPD), two-phase RFC 6479 1024-bit anti-replay with 64-bit ESN, and deterministic make-before-break SA rollover in freestanding C11.

Guarantees

Two-Phase Anti-Replay & Zero Heap

All state fits in a 1,944-byte caller-allocated struct with zero dynamic allocation. RFC 6479 1024-bit bitmap blocks advance strictly after Poly1305 authentication succeeds.

Portability

Strict Sans-IO Freestanding C11

Compiles with zero OS, socket, or stdio dependencies inside the library core. Runs identically across bare-metal Cortex-M/Zynq targets and Linux userspace UDP/TUN loops.

Rigor

Constant-Time & Channel Verified

Verified against RFC 8439 and RFC 7634 Appendix A test vectors, dudect timing analysis (|t| ≤ 4.5), and Gilbert-Elliott burst-loss reordering simulations.
