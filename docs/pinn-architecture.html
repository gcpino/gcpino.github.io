PINN · Computational Physics Architecture

Physics-Informed Neural PDE Solver

Direct unsupervised integration of the 1D parabolic heat diffusion equation using PyTorch automatic differentiation and composite boundary-residual loss.

Formulation

Zero Training Data

Trained purely on governing physical laws and boundary conditions. The neural network infers the full continuous solution space without any ground-truth field observations.

Mathematics

Exact Differential Operators

Uses PyTorch's computational graph to obtain analytical-grade spatial and temporal partial derivatives (∂u/∂t and ∂²u/∂x²), entirely eliminating mesh truncation errors.

Validation

Analytical Benchmark

Benchmarked on an 80×80 space-time grid against the Fourier analytical solution u(x, t) = exp(-α π² t) sin(π x), achieving relative L2 error of 1.6e-3.
