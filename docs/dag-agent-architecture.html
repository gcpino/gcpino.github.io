dag-agent · Architecture Specification

Bounded Colored Petri Net & Event-Sourced Agent Runtime

Formal workflow orchestration in pure Rust: static cycle and schema verification paired with an append-only SHA-256 event log and sub-millisecond time-travel replay.

Formal Semantics

Bounded Colored Petri Nets

Workflows are compiled as bipartite graphs with static schema verification, strict place capacity bounds, and DFS cycle guards that reject unbounded agent loops before execution.

Determinism

Event-Sourced Time Travel

Every state mutation is an immutable event chained with SHA-256 digests. Any historical marking can be reconstructed or forked into a new causal branch in microseconds without re-invoking LLM APIs.

Safety Invariants

Monotonic Resource Envelope

A hardware-style circuit breaker enforces strict upper bounds on token expenditure, step count, and refinement depth, guaranteeing strong termination across cyclic self-healing loops.
