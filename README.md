# gcpino.github.io

Source of my personal site: https://gcpino.github.io

A single static page (`index.html`, no build step, no framework, no
dependencies) with a hand-written WebGL shader hero, CSS scroll-driven
animations, and selected projects shown with their real output. Hosted on
GitHub Pages from the `main` branch.

To preview locally, open `index.html` in a browser. `test_portfolio.py` runs
basic checks on the page.
