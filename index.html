c-esp

Spec ↗ Source ↗

A standalone, zero-allocation, Sans-IO IPsec Encapsulating Security Payload (ESP) data-plane, Security Association (SA) lifecycle, and RFC 4301 Security Policy Database (SPD) engine implemented in freestanding C11. Encapsulates and authenticates packets in place using RFC 4303 framing, dual constant-time AEAD backends (RFC 7634 ChaCha20-Poly1305 at 6.81 cpb and table-free RFC 4106 AES-256-GCM), 64-bit Extended Sequence Numbers, and a two-phase RFC 6479 1024-bit anti-replay bitmap with make-before-break SA rollover.

CORE CONSTRAINTS Pure C11 (freestanding) · Sans-IO · 1,944 B context + 516 B SPD · Zero malloc/free
PROTOCOL & CRYPTO RFC 4303 ESP · RFC 7634 ChaCha20-Poly1305 (6.81 cpb) + RFC 4106 AES-256-GCM · RFC 4301 5-tuple SPD · RFC 3948 UDP-ESP
VERIFICATION GATE Two-phase RFC 6479 1024-bit anti-replay · dudect (|t| ≤ 1.95) + Valgrind ctgrind taint · Clang libFuzzer + Gilbert-Elliott sim

c-infer

Spec ↗ Source ↗

A standalone neural network inference runtime implemented in pure C11 without BLAS, external matrix libraries, or dynamic memory in the forward pass. Trained weights are serialized from PyTorch into a custom binary format (.cinf) and dispatched across a preallocated linear arena.

CORE CONSTRAINTS Zero malloc/free during forward pass · Static memory arena initialization
SUPPORTED LAYERS Linear, Conv2D, MaxPool2D, Flatten, ReLU, Sigmoid, numerically stable Softmax
VERIFICATION GATE Parity testing against PyTorch: < 1e-5 absolute tolerance on floating-point ops; bit-exact on pooling and flatten

PINN

Spec ↗ Source ↗

A Physics-Informed Neural Network solving the one-dimensional non-linear heat diffusion equation (∂u/∂t = α ∂²u/∂x²). Trained completely unsupervised without simulation ground truth by optimizing the partial differential equation residual directly through PyTorch automatic differentiation.

DOMAIN & CONDITIONS Domain: (x, t) ∈ [0, 1]² · IC: u(x, 0) = sin(πx) · BC: u(0, t) = u(1, t) = 0
NETWORK ARCHITECTURE Multi-Layer Perceptron (3 hidden layers × 32 units, Tanh activation)
ACCURACY BENCHMARK Relative L2 error: 1.6e-3 against exact Fourier analytical solution on an 80×80 grid
