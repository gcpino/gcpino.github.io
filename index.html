Projects

C / C++

forge

High-performance HTTP/1.1 server built from scratch in C. Event-driven I/O with epoll, POSIX thread pool for request handling, zero-copy sendfile, and a minimal routing layer. No external dependencies.

  • epoll-based event loop with edge-triggered mode
  • Fixed-size thread pool with task queue
  • Zero-copy static file serving via sendfile
  • Graceful shutdown with pending request draining
~900 LOC C11 Zero deps

Architecture: main thread accepts connections and pushes to a ring-buffer task queue. Worker threads pop tasks and handle HTTP parsing + response generation. Static files use Linux sendfile for kernel-space copy avoidance.

C11 epoll HTTP/1.1 threads

bedrock

Custom memory allocator implementing malloc, free, realloc, and calloc from scratch. Uses segregated free-lists for small allocations, a unified heap arena with first-fit search and coalescence for medium blocks, and direct mmap for large allocations. Thread-safe with a global mutex.

  • Segregated size-class bins (16B - 512B)
  • Heap arena with first-fit + boundary-tag coalescence
  • Direct mmap/munmap for allocations > 256 KB
  • Thread-safe via pthread_mutex
~800 LOC C11 mmap/brk

Block metadata uses boundary tags for O(1) coalescence. Small bins use LIFO free lists. The heap arena grows via sbrk and coalesces adjacent freed blocks. Large allocations bypass the heap entirely to reduce fragmentation.

C11 mmap allocator pthread

vault

Persistent key-value store with a write-ahead log, snapshot support, and a TCP text protocol. Hash table with FNV-1a hashing, read-write locks for concurrency, and an epoll-driven server. Supports GET, SET, DEL, EXISTS, and KEYS.

  • WAL with fsync per write for durability
  • Snapshot serialization to disk
  • Linear-probing hash table with FNV-1a
  • Text protocol over TCP with epoll server
~1200 LOC C11 WAL + Snapshots

Every mutation appends to the WAL before updating the in-memory hash table. On startup, the WAL is replayed to reconstruct state. Snapshots write the entire hash table to a binary file atomically. The server uses epoll with edge-triggered I/O and a thread-per-connection model with rwlocks for table access.

C11 WAL TCP epoll

Python

synapse

Neural network library built from scratch in pure Python. Implements feedforward networks with backpropagation, ReLU and sigmoid activations, MSE loss, and mini-batch gradient descent. No NumPy, no PyTorch — just the Python standard library.

  • Fully-connected layers with Xavier initialization
  • Backpropagation with chain rule
  • ReLU, Sigmoid, Tanh activations
  • Mini-batch SGD with configurable learning rate
  • Trains and evaluates on synthetic datasets
~500 LOC Python 3 Zero deps

Implements matrix operations (dot product, transpose, element-wise) from scratch using nested lists. Forward pass computes weighted sums and activations layer by layer. Backward pass applies the chain rule to compute gradients w.r.t. weights and biases. Supports configurable layer sizes, batch sizes, and epochs.

Python NN backprop from-scratch

ember

Minimal HTTP/1.1 server built in pure Python using only socket and select. Handles concurrent connections via select()-based I/O multiplexing, parses HTTP requests manually, and serves static files. No asyncio, no frameworks.

  • select()-based I/O multiplexing
  • Manual HTTP/1.1 request parsing
  • Static file serving with MIME types
  • Keep-alive and connection management
  • Single-threaded, event-driven
~400 LOC Python 3 socket + select

Uses socket in non-blocking mode with select() to multiplex read/write events across multiple client connections. Parses HTTP requests line-by-line using bytes operations. Response builder constructs proper HTTP/1.1 headers with Content-Length and Connection.

Python HTTP/1.1 select socket

cachet

In-memory key-value store with LRU eviction, TTL support, and a simple text protocol over TCP. Built with threading.Lock for concurrency and socketserver for the networking layer. Pure Python, zero dependencies.

  • LRU eviction using ordered dict (stdlib collections)
  • TTL per key with automatic expiration
  • TCP text protocol (SET, GET, DEL, KEYS, FLUSH)
  • Thread-safe with fine-grained locking
  • Optional AOF persistence (append-only file)
~350 LOC Python 3 LRU + TTL

Uses collections.OrderedDict for O(1) LRU operations (move_to_end + popitem). TTL is managed via a background thread that scans for expired keys. The TCP server uses socketserver.ThreadingTCPServer with a custom request handler that parses the text protocol and dispatches to the KV engine.

Python LRU TCP TTL

Simulation & Graphics

Ray tracing, rasterization, and fluid dynamics. Built from scratch.

trace

Minimal ray tracer in C. Renders spheres with recursive reflections, Phong shading (ambient, diffuse, specular), and shadow rays. Outputs a binary PPM image. Pure C99 with only libm.

  • Ray-sphere intersection with quadratic solver
  • Phong illumination model
  • Recursive reflections (up to 3 bounces)
  • Shadow rays for occlusion
  • Binary PPM output
~250 LOC C99 libm only

For each pixel, a primary ray is cast from the camera through the viewport. The closest sphere intersection determines the hit point. The normal at that point is used for Phong shading with multiple lights. Shadow rays check for occluders. Reflective materials spawn secondary rays recursively.

C99 ray-tracing Phong PPM

aster

Software 3D rasterizer in pure Python. Renders a rotating cube with a full transformation pipeline (model, view, projection, viewport), edge-function rasterization, Z-buffer, and flat shading.

  • 4x4 matrix math (translate, rotate, perspective)
  • MVP transformation pipeline
  • Edge-function triangle rasterization
  • Z-buffer hidden surface removal
  • Backface culling
  • Flat shading with diffuse light
~250 LOC Python 3 Zero deps

Vertices are transformed through model, view, and projection matrices. After perspective divide, NDC coordinates are mapped to screen space. Triangles are rasterized using edge functions with barycentric interpolation of Z for depth testing. Flat shading computes a single intensity per triangle from the face normal and light direction.

Python rasterizer Z-buffer PPM

wave

2D fluid simulation in C++ using a simplified Navier-Stokes solver. Advection, diffusion, and pressure projection produce divergence-free velocity fields. Density is transported through the field and rendered as grayscale PPM frames.

  • Semi-Lagrangian advection
  • Gauss-Seidel diffusion
  • Pressure projection (divergence-free)
  • Density transport visualization
  • Multi-frame PPM output
~250 LOC C++17 Zero deps

The velocity field is advanced by adding forces, diffusing viscosity, and projecting to a divergence-free state via a pressure Poisson solver (Gauss-Seidel). Density is advected through the resulting velocity field using semi-Lagrangian backtracing. Each frame writes the density field as a grayscale PPM image.

C++17 fluids Navier-Stokes PPM
