Projects

Selected systems work. Repositories available upon request.

forge

High-performance HTTP/1.1 server built from scratch in C. Event-driven I/O with epoll, POSIX thread pool for request handling, zero-copy sendfile, and a minimal routing layer. No external dependencies.

C11 epoll HTTP/1.1 threads

bedrock

Custom memory allocator implementing malloc, free, realloc, and calloc from scratch. Uses segregated free-lists for small allocations, a unified heap arena with first-fit search and coalescence for medium blocks, and direct mmap for large allocations. Thread-safe with a global mutex.

C11 mmap allocator pthread

vault

Persistent key-value store with a write-ahead log, snapshot support, and a TCP text protocol. Hash table with FNV-1a hashing, read-write locks for concurrency, and an epoll-driven server. Supports GET, SET, DEL, EXISTS, and KEYS.

C11 WAL TCP epoll
